# Review: v0.7.1 map route state (D-083)

Reviewer: Codex (cross-model). Base: origin/main. Head: 646a319.

- **P1 — D-082 parity fails for zero-weight Service refs.** `web/packages/shell/src/pages/map/graph.ts:256` requires a backend finding signal on that row. But `pkg/paths/project.go:673` omits Service findings when weight is zero, while `pkg/explore/rows.go:552` lifts routes regardless of weight. With an active KGWUI-023 on that Service, the visible map route can remain healthy while its detail is warning. Port-specific signal filtering can cause the same disagreement.

- **P2 — Collapsing delegation misattributes backend problems.** `web/packages/shell/src/pages/map/graph.ts:255` selects the last *visible* route. For `root → child → bad Service`, collapsing root puts the finding in root’s `backendProblems`; `SidePanel.tsx:273` displays it as root’s problem instead of under hidden child. D-082 leaves a delegation-only root healthy; the map’s existing collapse design attributes hidden-route problems under their names. Warning roll-up is reasonable, but this loses the responsible route.

Tests were not run; author-reported results were supplied.
